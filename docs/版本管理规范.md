# 版本管理规范（SemVer）

> 版本：v1.0　|　日期：2026-08-03　|　适用：全团队（A/B/C）
> 依据：https://semver.org/lang/zh-CN/

---

## 1. 为什么统一版本号

此前版本号分散在多个位置且不一致：

| 位置 | 旧值 | 问题 |
|------|------|------|
| `pyproject.toml` | 0.1.0 | 权威但长期未更新 |
| `backend/main.py` | 0.4.0 | 手写，与 pyproject 不一致 |
| `backend/mcp/weather_server.py` | 1.0.0 | 独立进程，体系游离 |

统一后所有组件版本号一致，单一来源，杜绝手写冲突。

## 2. 单一事实来源

**唯一权威**：`backend/version.py`

```python
__version__ = "1.1.0"   # 改版本只改这一处
VERSION = _from_pyproject()  # 构建时与 pyproject.toml 自动同步
```

所有组件统一引用：
- **FastAPI 应用**：`main.py` 读 `from version import VERSION`
- **MCP Server**：`weather_server.py` 读 version.py（importlib 加载规避 mcp 包遮蔽）
- **Python 包**：`pyproject.toml` 的 `version` 字段

> **规则：改版本号只改 `backend/version.py` 与 `pyproject.toml` 两处，禁止在其他文件手写版本号。**

## 3. 语义化版本（SemVer）

格式：`MAJOR.MINOR.PATCH`

| 段 | 何时 +1 | 示例 |
|----|---------|------|
| **MAJOR** | 不兼容的 API 变更 | 0.6.0 → 1.0.0 |
| **MINOR** | 向后兼容的新功能 | 0.6.0 → 0.7.0 |
| **PATCH** | 向后兼容的缺陷修复 | 0.6.0 → 0.6.1 |

### 当前阶段

项目处于 **0.x 初期开发**（D1~D7 已完成约 6 个能力块）：

| 版本 | 对应里程碑 |
|------|-----------|
| 0.1.0 | D1~D2 基础雏形（链路 + search + recommend） |
| 0.2.0 | D3 摄入记录 + 多轮记忆 |
| 0.3.0 | D4 优化 + 子 Agent + RAG |
| 0.4.0 | D5 中间件 + Store |
| 0.5.0 | D6 天气 MCP + 流式 |
| **0.6.0** | **D7 修复 + 部署（当前）** |
| 1.0.0 | 对外承诺 API 稳定后发布 |

## 4. 升级流程（提交 PR 时）

### 何时升版本

- **修 bug**（不改 API / 行为）：PATCH `0.6.0 → 0.6.1`
- **加功能**（向后兼容）：MINOR `0.6.0 → 0.7.0`
- **破坏性变更**（改接口 / 删功能）：MAJOR `0.6.0 → 1.0.0`
  - 0.x 阶段也可按社区惯例用 MINOR 承载破坏性变更，但**需在 PR 描述注明**

### 改哪些文件

```bash
# 1. 更新 backend/version.py 的 __version__
# 2. 更新 pyproject.toml 的 version
# 3. 有接口变更时同步 docs/BC-API文档.md 的版本与状态
```

### 验收

- [ ] `backend/version.py` 与 `pyproject.toml` 版本一致
- [ ] `GET /health` 或 `/docs` 显示的版本 = 新版本
- [ ] 无其他文件残留手写版本号
  - 检查命令：`rg "0\.\d+\.\d+" backend --glob '!version.py' --glob '!pyproject.toml'`

## 5. 文档版本（与软件版本分离）

`docs/*.md` 的 `版本：v1.x` 是**文档修订号**，不参与软件版本语义：
- 文档内容修订 → 递增文档版本
- 不随软件 MINOR/PATCH 自动联动
- 接口变更时需同步 `BC-API文档.md`（这是文档修订 + 版本标注）

## 6. 快速检查当前版本

```bash
cd backend
uv run python -c "from version import VERSION; print(VERSION)"
# 期望输出 0.6.0
```
